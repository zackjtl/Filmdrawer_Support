Support

Found a bug or have a question? Open an issue on GitHub

Please include your macOS version, the Filmdrawer version (Filmdrawer ▸ About Filmdrawer), and what you were doing when the problem happened.

Common questions

A memory card is inserted but nothing happens.
The card needs a DCIM folder at its top level. The first time you use each card, Filmdrawer asks for permission: click “Authorize and Sync…”, then click “Authorize” in the file dialog without opening any folder inside the card.
Where are my photos?
In ordinary folders inside your library (by default Pictures/Filmdrawer), one folder per Project, sorted into year/date folders. Right-click a photo and choose “Show in Finder”.
I bought the full version on another Mac.
Open Settings ▸ General and click “Restore Purchases” while signed in to the same Apple ID.
Will deleting Filmdrawer delete my photos?
No. Your photos are ordinary files and stay where they are.

常見問題

插了記憶卡但沒有反應
記憶卡最上層要有 DCIM 資料夾。每張卡第一次使用時，Filmdrawer 會請你授權：按「授權並同步…」，在檔案視窗中直接按「授權」，不要點進卡裡的資料夾。
照片存在哪裡？
存在照片庫裡的一般資料夾（預設是「圖片／Filmdrawer」），每個 Project 一個資料夾，再依年份與日期分類。在照片上按右鍵選「在 Finder 中顯示」即可找到。
我在另一台 Mac 買過完整版
用同一個 Apple ID 登入，到「設定 ▸ 一般」按「恢復購買」。
刪除 Filmdrawer 會刪掉照片嗎？
不會。照片都是一般檔案，會留在原本的位置。

常见问题

插入了存储卡但没有反应
存储卡最上层要有 DCIM 文件夹。每张卡第一次使用时，Filmdrawer 会请你授权：点按“授权并同步…”，在文件窗口中直接点按“授权”，不要点进卡里的文件夹。
照片存放在哪里？
存放在照片库里的普通文件夹（默认是“图片／Filmdrawer”），每个 Project 一个文件夹，再按年份与日期分类。在照片上按右键选“在访达中显示”即可找到。
我在另一台 Mac 上买过完整版
用同一个 Apple ID 登录，到“设置 ▸ 通用”点按“恢复购买”。
删除 Filmdrawer 会删掉照片吗？
不会。照片都是普通文件，会留在原来的位置。

よくある質問

メモリーカードを挿しても何も起きない
カードの最上位に DCIM フォルダが必要です。各カードを初めて使うときは許可を求められます。「許可して同期…」をクリックし、ファイルダイアログでカード内のフォルダを開かずにそのまま「許可」をクリックしてください。
写真はどこに保存されますか？
ライブラリ内のふつうのフォルダ（初期設定は「ピクチャ／Filmdrawer」）に、Project ごとのフォルダで年・日付別に保存されます。写真を右クリックして「Finder で表示」を選ぶと見つかります。
別の Mac でフル版を購入しました
同じ Apple ID でサインインし、「設定 ▸ 一般」で「購入を復元」をクリックしてください。
Filmdrawer を削除すると写真も消えますか？
いいえ。写真はふつうのファイルなので、そのまま残ります。

지원

버그를 발견했거나 질문이 있으신가요? GitHub Issue 남기기

macOS 버전, Filmdrawer 버전(Filmdrawer ▸ Filmdrawer에 관하여), 문제가 발생했을 때 하던 작업을 함께 적어 주십시오.

자주 묻는 질문

메모리 카드를 꽂았는데 아무 반응이 없습니다
카드 최상위에 DCIM 폴더가 있어야 합니다. 각 카드를 처음 사용할 때 허용을 요청합니다. ‘허용하고 동기화…’를 클릭한 다음, 파일 창에서 카드 안의 폴더를 열지 말고 바로 ‘허용’을 클릭하십시오.
사진은 어디에 저장되나요?
보관함(기본값은 ‘사진/Filmdrawer’) 안의 일반 폴더에 Project별로, 연도와 날짜 폴더로 나뉘어 저장됩니다. 사진을 오른쪽 클릭하고 ‘Finder에서 보기’를 선택하면 찾을 수 있습니다.
다른 Mac에서 정식 버전을 구입했습니다
같은 Apple ID로 로그인한 후 ‘설정 ▸ 일반’에서 ‘구입 복원’을 클릭하십시오.
Filmdrawer를 삭제하면 사진도 삭제되나요?
아니요. 사진은 일반 파일이므로 그대로 남아 있습니다.
